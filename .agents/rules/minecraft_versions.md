# Minecraft Versioning Rule

**CRITICAL:** When the user specifies a version of Minecraft like "26.2" or "26.1.2", **DO NOT ASSUME** it refers to older formats like 1.21.4 or 1.21.11. 

1. **Accept the Version:** Treat "26.2" as the literal, official Java Edition version number.
2. **Verify via Web Search:** If you are unfamiliar with the version, **do not guess**. Immediately use the `search_web` tool or search the Minecraft Wiki (e.g., "Minecraft 26.2 Java Edition") to confirm the version details.
3. **No Correction:** Do not attempt to "correct" the user about version numbers. If they say a version exists, it exists. Search for it if you need the technical details.

Violating this rule causes severe friction. Always trust the user's version string.
